# C-1 既存深耕 プレイブック

売上の土台であり、最も確度が高い領域。関与先308件（うち税務顧問171先）に対して「今より深く関わる」ための打ち手を並べる。
売上・単価を語るときは171先、担当者の負荷や記帳代行を語るときは308件を使う。
数字の根拠は `context.md` を参照。

## この領域の構造

税務顧問171先のLTV分布がすべてを規定している（三か年事業計画の確定値）。

```
上位20%（35件）  ─ 売上の46.3%（3,356万円・平均95.9万円）→ 守る
中位60%（106件） ─ 売上の50.5%（3,662万円・平均34.5万円）→ 伸ばす（+10万円/社で+1,060万円）
下位20%（35件）  ─ 売上の 3.6%（  262万円・平均 7.5万円）→ 整理する
```

下位35件は月額換算6,200円/社。件数は上位と同じ35件なのに売上は13分の1。ここが工数を食っている。

上位を守る施策と中位を伸ばす施策は、動機も手法も別物として扱う。混ぜると両方が薄まる。

## 打ち手カタログ

### 1. 単価改定（最も確度が高い）

**なぜ効くか**: 2023・2025・2026年と3回通した実績があり、解約はコントロールできている。
新規獲得ゼロでも売上が増え、追加工数がほぼ発生しない。人手が増えない制約下で唯一の即効薬。

**やり方**:
- 対象は「報酬÷工数」が事務所平均を下回る先。工数データが無ければ関与レベルA/B（＝手間が重い）かつ報酬が中位以下の先で代替する
- 改定率は既存実例（+25%程度）を上限の目安に、5〜15%を標準幅に置く
- 通知文はDriveのひな形を流用（【フォーム（契約内容見直し）】）
- 「①承諾 ②契約内容の見直し ③解約」の3択形式にすると、②に落ちて実質的な減工数交渉ができる

**リスク**: 上位35件に一律で当てるのは危険。ここは個別交渉に切り替える。

### 2. 中位60先へのアップセル

**なぜ効くか**: 母数が106件と厚く、+10万円/社なら顧問先の心理的抵抗が小さい。
+1,060万円は令和11年度2億1,902万円という目標に対する寄与が大きい。
計画上のC-1 KPI「既存単価 年5%成長＝三年で+2,118万円」の主要な達成手段でもある。

**やり方**: `中位60_アップセル機会表_v1.xlsx` を使う。報酬額を入れると層判定と優先度スコアが出る。
優先度スコア4以上（＝戦略整合性「高」＋商品候補◎が複数）から着手する。

**商品の当て方**:

| 顧問先の状態 | 提案する商品 | 単価目安 |
|---|---|---|
| 記帳代行あり（161件） | 経理コンサル（記帳の内製化支援） | +10〜30万円/年 |
| 関与レベルA/B（47件） | 伴走型サポート（定期面談・経営助言） | +12〜36万円/年 |
| 高齢オーナー・自社株あり | コンパクト相続（試算＋対策提案） | 単発20〜50万円 |
| クラウド未導入 | クラウド会計導入支援 | 導入費＋月額上乗せ |

**注意**: 記帳代行ありの先に経理コンサルを売ると、記帳代行報酬が減る可能性がある。
「記帳代行を止めてもらう」のではなく「取引量増に耐える体制を作る」という設計にして、
記帳代行を維持したまま上乗せする形にするのが安全。

### 3. 上位35件のリテンション

**なぜ効くか**: 1件失うと平均95万円/年、売上の1.3%が消える。新規で埋めるには2〜3件の獲得が要る。

**やり方**:
- NPSアンケートを上位35先に先行実施（設計は `NPSパイロット実施設計_v1.md`）
- 批判者（0-6点）は48時間以内に所長＋担当者で対応方針を決める
- 担当者の属人化を確認する。1人が持つ上位先が3件を超えていたら、退職・異動リスクが売上リスクに直結する
- 所長が年1回は必ず顔を出す先として明示的にリスト化する

**判断材料**: 解約の予兆は「面談頻度の低下」「質問の減少」「支払遅延」に出る。
未入金リストは既にDriveにあるので、2ヶ月以上未入金＝リスク先として扱える。

### 4. 下位20%（35件）の整理

**なぜ効くか**: 売上の3.6%しか生まないのに件数は上位と同じ35件で、担当者の時間は件数比例で取られる。
人手が制約なら、ここを整理して中位・上位に時間を移すのが合理的。

**やり方**（穏当な順）:
1. ランクDに落として対応レベルを下げる（面談年1〜2回、数値確認中心）
2. 業務支援部・総務に担当を移し、有資格者の時間を空ける
3. 単価改定を当てる（受け入れられれば収益改善、断られれば自然離脱）
4. 解約提案（最終手段。紹介元との関係を必ず確認する）

**注意**: 下位先が上位先の関連会社・紹介元であることがある。単体の収益だけで切ると関係全体を失う。
グループ関係の確認を必ず提案に含める。

### 5. クロスセル（グループ・関連会社）

**なぜ効くか**: 既に信頼がある先の関連会社は、新規開拓より受注確率が桁違いに高い。獲得コストがほぼゼロ。

**やり方**: 顧問先リストで同一オーナー・同一グループを名寄せし、未関与の法人を洗い出す。
既存の関与先で「グループ内に当事務所が見ていない会社がある」ケースを担当者ヒアリングで拾う。

## C-1で提案してはいけないこと

- **上位4名（純夫・松崎・荻原・柳）に新規の定期訪問を積む施策**: 4名で151件を持っている。物理的に回らない
- **全308先への一斉施策**: 層別しない提案は実行されない。必ず対象を絞る
- **NPS結果を前提とした施策**: まだ実施していない。推定であることを明示する
