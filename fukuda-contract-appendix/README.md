# 顧問契約書 別紙1（税理士法人 福田会計）

サリーレ群馬税理士法人の「会計顧問契約書」1枚目（月額顧問料に「含む／含まない」を☑で示す一覧表）の書式をベースに、
福田会計の見積書項目を契約別紙として整理したもの。

## ファイル

| ファイル | 内容 |
|---|---|
| `別紙1_契約業務内容および報酬内訳_福田会計.docx` | 納品物（A4縦1〜2枚） |
| `build_appendix.js` | 上記docxの生成スクリプト（docx-js） |

## 再生成

```bash
npm install docx
node build_appendix.js 別紙1_契約業務内容および報酬内訳_福田会計.docx
```

## 構成

元書式の1区分（含む／含まない）を、先方意見をふまえて3区分に分けた。

- **Ⅰ 月額顧問報酬に含まれる業務**（毎月）… 基本報酬・記帳代行・試算表・打合せ方法・給与計算・納税代行・労社保手続・支払方法
- **Ⅱ 決算・申告業務**（事業年度ごと。税務顧問報酬に含む）… 決算報酬・消費税申告・書面添付・各種印刷・NXPRO減額・出精値引き
- **Ⅲ 選択的追加業務**（含まない。利用の都度、事前合意）… 算定基礎届・年末調整・税務調査立会・届出書・自計化支援・資産税・頻度追加・他士業業務

## 先方意見の反映点

1. **別紙の位置づけ** — 注1で「本別紙及び別紙2『報酬規定』は本契約の一部を構成し、変更は甲乙双方の書面又は電磁的方法による合意を要する」と明記。
2. **事業規模（年商）基準の廃止** — 見積書の「年商5,000万円ごとに＠5,000加算」行を削除。注2で「売上高を基準とする報酬の加算は行わない」と宣言し、業務量基準を年間仕訳数に一本化（1事業年度4,800仕訳まで月額報酬に含み、超過分は1仕訳＠50円で精算）。
3. **試算表頻度・訪問の切り分け** — 区分Ⅰ(3)(4)で契約上のサービス内容として頻度・方法をチェック方式で明示。合意頻度を超える分は区分Ⅲ(27)の選択メニューとして都度事前合意（注3）。
4. **書面添付** — 区分Ⅱ(15)で「含む」に☑。決算報酬に含め別途報酬は請求しない旨を注5に記載（見積書の＠30,000は単独請求しない整理）。

## 未確定・要確認事項

- 仕訳数の下限：見積書は「年1,200件超は1仕訳＠50」、先方は「契約書第2項で4,800仕訳」と認識。本別紙は**4,800仕訳**で作成。契約書本文と要突合。
- 事業規模加算（月額＠20,000相当）の廃止に伴う月額報酬の再設定。
- 別紙2「当事務所報酬規定」は本別紙から参照しているのみで、別途作成が必要。
