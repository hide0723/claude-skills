# 共通フォーム

福田会計側で編集された様式（「含まない」列を削除して「含む」1列＋「備考」列、区分ごとの小計行）を踏襲した、記入用の空フォーム。**1ファイル3枚組**で、改ページで別紙1〜別紙3に分かれる。

## 構成

列: 番号／品番・品名／含む／数量／単価／金額（税抜）／備考

### 別紙1　契約業務内容および報酬内訳（税務顧問業務・決算申告代行業務）

| 区分 | 項目 | 小計行の単位 |
|---|---|---|
| 税務業務 | 1〜6 | 月額／年額 |
| 決算・申告代行業務 | 7〜14 | 年額のみ（単価欄は －） |
| 合計 | — | 小計（税抜）／消費税（10％）／お値引き（税込）／合計（税込） |

項目1は「税務監査、税務相談業務：」（副題に「基本月額報酬」）。委任する業務の内容を示す名称にし、報酬名は副題に残している。

### 別紙2　その他業務の報酬（年末調整代行業務・償却資産申告業務ほか料金表）

別紙1・別紙3の月額報酬に含まれない業務の料金表。金額が確定しているため記入欄は設けず、単価を明示した固定の料金表とする。列は 項目／単位／報酬額（税抜）。

| 区分 | 内容 |
|---|---|

| 2 支払調書の作成代行 | 所得税法第204条第1項報酬 ￥1,500／件 |
| 3 償却資産税申告書の作成代行 | ￥10,000／一自治体 |

| 5 株式評価（個別お見積もり） | 初回 ￥100,000〜、2回目以降 ￥50,000〜 |
| 6 所得税・贈与税申告書の作成代行 | 確定申告書 第1表・第2表 ￥20,000／件、収支内訳書・青色申告決算書（損益のみ）￥30,000、青色申告決算書（貸借対照表あり）は別紙1に含む、消費税申告書 ￥30,000、付表・明細 ￥10,000／種類、譲渡所得申告 ￥100,000、給与所得以外の収入300万円以下は △￥10,000、贈与税申告書＋贈与契約書 ￥10,000／組 |
| 7 税額控除に係る報酬 | 法人税申告書別表一「法人税額の特別控除額の合計を記載する欄」の金額×5％、上限 ￥500,000／事業年度 |

出典は事務所内資料「250600_報酬額のご案内」（区分1〜3、5）および「260309_所得税・贈与税申告書 作成代行報酬のご案内」（区分6）。区分4、7〜9は福田会計からの直接指示による。「250600_報酬額のご案内」の月額税務報酬・給与計算代行報酬・決算報酬は別紙1・別紙3に反映済みのため、別紙2には重複させていない。

#### 修正申告の報酬額について

「250600_報酬額のご案内」は修正申告を ￥20,000／1事業年度としていたが、福田会計からの指示は ￥30,000／1税目1事業年度。同一文書内に異なる2つの単価が並ぶのを避けるため、**指示のあった ￥30,000／1税目1事業年度に一本化**し、旧「税務申告（その他）修正申告 ￥20,000」の行は削除した。自主的な修正申告と税務調査に伴う修正申告で単価を分ける場合は、行を分けて併記する必要がある。

#### 別紙2の注記から変更手続の条項が落ちている

福田会計側の編集で、別紙2（料金表）の注記から「本別紙は本契約の一部を構成する。本別紙の変更は、甲乙双方の書面又は電磁的方法による合意によらなければ、その効力を生じない。」が削除された。前文に「本契約の一部を構成する」旨は残るが、**変更手続の定めは別紙2にのみ無い状態**（別紙1・別紙3には残る）。先方が求めていた条件なので、復活させるか要確認。

### 別紙3　契約業務内容および報酬内訳（給与計算代行業務）

| 区分 | 項目 | 小計行の単位 |
|---|---|---|
| 給与計算代行 | 1〜7 | 月額／年額 |
| 合計 | — | 小計（税抜）／消費税（10％）／合計（税込） |

給与計算代行は税務顧問と発注の有無が分かれるため、別紙を分けて単独で締結・改定できる形にしている。項目番号は別紙ごとに1から振り直し、甲乙・原契約・前文・注記・合計欄も独立して持たせている。

注記は共通4項目（含む欄の意味、別紙2への参照、別紙の変更手続、消費税率）を別紙1・別紙3に置き、勤怠管理に係る注記は別紙3にのみ置く。

なお、合計欄の「お値引き（税込）」行は別紙1にのみあり、別紙3には無い（福田会計側の編集どおり）。

### 見積書からの差異

- **記帳代行の仕訳超過分は別紙1の総額に含めない。** 仕訳数の加算は決算時のみ請求するため、明細行「なお、年仕訳数1,201件～＠50にて別途請求」は数量・単価・金額を空欄とし、備考に「決算時に別途請求」と記載。単価と請求時期は別紙2の区分9に掲げ、別紙4第2条第2項にも決算時に一括請求する旨を明記した。
- **別紙3は勤怠集計・給与明細印刷・労働保険社会保険手続き一式・労働保険の算定基礎届を契約外（☐）とした。** 契約内は給与計算の基本月額報酬・人数割・住民税のダイレクト納付で、月額 15,400円／年額 184,800円。
- 上記の結果、別紙1の税務業務小計は 月額 65,000円／年額 780,000円（＝65,000×12）。

## 現契約との差額の値引き処理

現契約（`231214_顧問契約書_㈱ブリスオーディオ【202401改定】.pdf`、令和6年1月改定）の報酬。

| | 月額（税込） | 年額（税込） | 年額（税抜） |
|---|---:|---:|---:|
| 税務顧問報酬（決算報酬・書面添付を含む） | 52,800 | 633,600 | 576,000 |
| 給与計算代行 | 11,660 | 139,920 | 127,200 |
| **合計** | **64,460** | **773,520** | **703,200** |

新見積との差額を「お値引き（税込）」欄で調整し、**税込の年額合計を現契約と同額の 773,520円に据え置いている**。

- 別紙1: 1,078,000 − 633,600 = △444,400（税抜 △404,000、消費税 △40,400）
- 別紙3: 203,280 − 139,920 = △63,360（税抜 △57,600、消費税 △5,760）

値引きは「お値引き（税込）」欄に置き、小計（税抜）・消費税（10％）は値引き前の金額のままとした。区分小計も値引き前の数値なので、標準報酬と実際の請求額の両方が1枚で追える。明細の「出精値引き」行（別紙1 項目13）は☐のままとし、備考に「下記お値引き欄にて調整」と記載している。

値引きの根拠・適用期間は別紙1・別紙3の注記※3と別紙4第11条に記載。

### 別紙4第11条は追加提案

**第11条（お値引き）は指示になかったものを追加している。** 値引き額が年額 507,760円（税込）と大きく、適用期間を書かないと自動継続で恒久化するおそれがあるため、本契約期間限りとし次期以降は協議とする条項を置いた。期中に業務範囲・数量が変わった場合の扱いも協議事項としている。不要であれば削除可。

区分小計は 単価欄に月額、金額欄に年額を記載。税務業務は 月額 ¥65,000／年額 ¥780,000、決算・申告代行業務は 年額 ¥200,000、給与計算代行は 月額 ¥15,400／年額 ¥184,800。

☑を付したのは契約に含む項目。訪問（来所・オンラインのため）、口座振替以外、各種印刷、NXPRO、出精値引き、および別紙3の項目3・4・6・7は☐のまま金額0とし、単価は残している。

仕訳超過分は別紙1の総額に含めず、決算時に精算（ブリスオーディオ版と同じ扱い）。ただし超過の有無は基準により分かれる（下記「仕訳数の基準」参照）。

## 現契約と値引き

現契約は `240529_顧問契約書_㈱岡田ＨＤ.xlsx` のシート「記帳代行あり給与無し」（令和6年5月29日付、令和6年4月より1年間・自動継続）。

- 税務顧問報酬 月額 28,050円（税込）＝ **年額 336,600円**。決算報酬・書面添付を含む
- 給与計算代行の定めなし（委任範囲は 税務申告及び税務監査／税務相談及び税務調査立会い／記帳代行／書面添付／その他別途協議）

**別紙1のみ現契約の年額に据え置き**（お値引き △158,400円＝税抜 △144,000円）。**別紙3の給与計算代行は現契約の委任範囲に無い新規業務のため、値引きの対象としていない。** 総額を336,600円に据え置く場合は別紙3も全額値引き（△75,020円）になるが、新規業務を無償提供する形になるため採用していない。

## 見積書の記載で要確認の3点

- **項目4 月次経理処理頻度は 12ケ月×＠5,000＝60,000（年4回）で確定**（福田会計の指示）。見積書は「3ケ月×＠15,000＝45,000」だったが、月額が揃ったため税務業務の区分小計は 月額25,000／年額300,000 として月額・年額の両方を表示している。
- **別紙3 項目1 給与計算基本月額報酬が「1ヶ月×＠4,000＝4,000」**。他の項目が12ヶ月なのに対しこれだけ1ヶ月。見積書どおりとし、注記※3に根拠を記載。12ヶ月なら48,000円になるため要確認。
- **書面添付は見積書に金額の記載がないが、実施する前提で計上している**（福田会計の指示）。従前の顧問契約書でも委任範囲(4)に「税理士法第33条の2第1項に規定する添付書面の添付」が入っていた。項目14を☑（＠30,000）とし、根拠を注記※4に記載。
