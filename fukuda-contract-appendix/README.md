# 顧問契約書 別紙1（税理士法人 福田会計）

サリーレ群馬税理士法人の「会計顧問契約書」1枚目（月額顧問料に「含む／含まない」を☑で示す一覧表）の書式をベースに、
福田会計の見積書項目を契約別紙として整理したもの。

## ファイル

2種類ある。用途が違うので取り違えに注意。

| ファイル | 内容 |
|---|---|
| `別紙_契約業務内容および報酬内訳_共通フォーム_福田会計.docx` | **共通フォーム（本命）**。関与先ごとに記入して使う空フォーム |
| `build_form.js` | 上記の生成スクリプト |
| `別紙_契約業務内容および報酬内訳_ブリスオーディオ.docx` | **見積書準拠版**。見積書 20260725-003 の項目順・項目名をそのまま使い、㈱ブリスオーディオの実数値（数量・単価・金額）を記載。合計 1,724,415円（税込） |
| `build_appendix_bliss.js` | 上記の生成スクリプト |
| `別紙1_契約業務内容および報酬内訳_福田会計.docx` | **先方意見反映版**。3区分に再構成し、事業規模基準の廃止等を反映。共通フォームとは列構成が異なる旧案 |
| `build_appendix.js` | 上記の生成スクリプト |

## 再生成

```bash
npm install docx
node build_form.js 別紙_契約業務内容および報酬内訳_共通フォーム_福田会計.docx
node build_appendix_bliss.js 別紙_契約業務内容および報酬内訳_ブリスオーディオ.docx
node build_appendix.js 別紙1_契約業務内容および報酬内訳_福田会計.docx
```

# 共通フォーム

福田会計側で編集された様式（「含まない」列を削除して「含む」1列＋「備考」列、区分ごとの小計行）を踏襲した、記入用の空フォーム。**1ファイル2枚組**で、改ページで別紙1と別紙2に分かれる。

## 構成

列: 番号／品番・品名／含む／数量／単価／金額（税抜）／備考

### 別紙1　契約業務内容および報酬内訳（税務顧問業務・決算申告業務）

| 区分 | 項目 | 小計行の単位 |
|---|---|---|
| 税務業務 | 1〜6 | 月額／年額 |
| 決算・申告業務 | 7〜14 | 年額のみ（単価欄は －） |
| 合計 | — | 小計（税抜）／消費税（10％）／合計（税込） |

### 別紙2　契約業務内容および報酬内訳（給与計算代行業務）

| 区分 | 項目 | 小計行の単位 |
|---|---|---|
| 給与計算代行 | 1〜7 | 月額／年額 |
| 合計 | — | 小計（税抜）／消費税（10％）／合計（税込） |

給与計算代行は税務顧問と発注の有無が分かれるため、別紙を分けて単独で締結・改定できる形にしている。項目番号は別紙ごとに1から振り直し、甲乙・原契約・前文・注記・合計欄も別紙2に独立して持たせている。

注記は共通3項目（含む欄の意味、別紙の変更手続、消費税率）を両別紙に置き、勤怠管理に係る注記は別紙2にのみ置く。

> **注意**: 旧案の `別紙1_契約業務内容および報酬内訳_福田会計.docx` は「別紙2＝当事務所報酬規定」という前提で書かれており、この共通フォームの別紙2（給与計算代行）と番号が衝突する。旧案を使う場合は参照先の名称を要調整。

## 元ファイルからの修正点

1. **合計行の復旧** — 「小計」「消費税(10%)」「合計」のラベルが欠落し金額だけの2セル行になっていたのを、ラベル＋金額欄の形に戻した。ラベルは金額欄の直前まで結合して右寄せ。
2. **決算・申告業務の小計行を追加** — 税務業務・給与計算代行には小計行があるのに決算・申告業務にだけ無かったため追加。単位は「事業年度」（他2区分は「月額／年額」）。
3. **項目20と21の間の空行を削除。**
4. **「含まない」列の削除に伴う文言修正** — 前文と注記が「「含まない」欄に☑を付した業務は…」と、既に存在しない列を指していたため、「☑を付していない業務は…」に改めた。
5. **注記の番号を振り直し** — ※2 が欠番で、項目9の「※2」参照先が無くなっていたため ※1〜※4 に通し直し、項目9の参照も ※1 に修正。
6. **誤字修正** — 「勤簿及びタイムカード」→「出勤簿及びタイムカード」。
7. **末尾の日付欄を「以上」に変更** — 記名押印は本紙で行うため、別紙に日付欄のみ残るのは不自然。

## 空欄化した箇所

関与先ごとに記入する。単価は福田会計の標準単価として残してある。

- 委任者（甲）名、原契約の日付
- 「含む」欄の☑（全項目 ☐ に統一）
- 数量のうち関与先依存のもの（人数・部数・訪問有無に係る月数）
- 金額欄（全行）、小計・合計欄
- 項目5の年商、項目4の単価（頻度により変動）、項目14の単価（法人／個人で変動）
- 備考欄は選択肢の目安を記載（来所／オンライン／訪問、年○回、○○万円想定、振替口座、法人／個人・NPO）

# 見積書準拠版（ブリスオーディオ）

見積書 20260725-003（2026年7月25日、合計 ¥1,724,415）の22項目を、順序・文言ともそのまま1行1項目で転記した。

- 列構成：番号／品番・品名／含む／含まない／数量／単価／金額
- 見積金額が入っている項目 → 「含む」に☑
- 見積金額が空欄の項目（訪問・口座振替以外・各種印刷・NXPRO・出精値引き）→ 「含まない」に☑、単価は残して金額0
- 見積書で選択制になっている項目には、ブリスオーディオでの選択内容を補記（訪問なし／年4回／法人／口座振替）
- 小計・消費税・合計を表末に配置。明細合計 1,567,650円は見積書の小計と一致することを検証済み

## 見積書との相違点で要確認

- 有効期限が「2026年02月28日」と見積書発行日（2026年7月25日）より前になっている。ひな型の残りと思われるため、別紙には転記していない。
- 「年仕訳数1,201件～＠50」の行は、見積書上は数量4,325件（＝5,525−1,200）。別紙にも同じ計算式を補記した。

# 先方意見反映版（汎用ひな型）

## 記名押印について

**別紙には甲乙の記名押印欄を設けていない。** 締結は本紙（顧問契約書）末尾の記名押印のみで行い、別紙は本紙と一体として綴じる。元にしたサリーレ群馬税理士法人の契約書も同じ構成で、1枚目の一覧表には署名欄がなく、署名は本文最終ページのみに置かれている。

本紙との一体性は次で担保する。

- 本紙の該当条項に「業務の範囲及び報酬は別紙のとおりとする」旨を明記する
- 本紙と別紙を一体として製本し、頁の綴じ目に契印（又は割印）を行う
- 別紙冒頭に「本別紙は本契約の一部を構成する」旨を記載（両ファイルとも記載済み）
- 別紙の変更には双方の書面又は電磁的方法による合意を要する旨を注記に記載（両ファイルとも記載済み）

## 構成

元書式の1区分（含む／含まない）を、先方意見をふまえて3区分に分けた。

- **Ⅰ 月額顧問報酬に含まれる業務**（毎月）… 基本報酬・記帳代行・試算表・打合せ方法・給与計算・納税代行・労社保手続・支払方法
- **Ⅱ 決算・申告業務**（事業年度ごと。税務顧問報酬に含む）… 決算報酬・消費税申告・書面添付・各種印刷・NXPRO減額・出精値引き
- **Ⅲ 選択的追加業務**（含まない。利用の都度、事前合意）… 算定基礎届・年末調整・税務調査立会・届出書・自計化支援・資産税・頻度追加・他士業業務

## 先方意見の反映点

1. **別紙の位置づけ** — 注1で「本別紙及び別紙2『報酬規定』は本契約の一部を構成し、変更は甲乙双方の書面又は電磁的方法による合意を要する」と明記。
2. **事業規模（年商）基準の廃止** — 見積書の「年商5,000万円ごとに＠5,000加算」行を削除。注2で「売上高を基準とする報酬の加算は行わない」と宣言し、業務量基準を年間仕訳数に一本化（1事業年度4,800仕訳まで月額報酬に含み、超過分は1仕訳＠50円で精算）。
3. **試算表頻度・訪問の切り分け** — 区分Ⅰ(3)(4)で契約上のサービス内容として頻度・方法をチェック方式で明示。合意頻度を超える分は区分Ⅲ(27)の選択メニューとして都度事前合意（注3）。
4. **書面添付** — 区分Ⅱ(15)で「含む」に☑。決算報酬に含め別途報酬は請求しない旨を注5に記載（見積書の＠30,000は単独請求しない整理）。

## 未確定・要確認事項

- 仕訳数の下限：見積書は「年1,200件超は1仕訳＠50」、先方は「契約書第2項で4,800仕訳」と認識。本別紙は**4,800仕訳**で作成。契約書本文と要突合。
- 事業規模加算（月額＠20,000相当）の廃止に伴う月額報酬の再設定。
- 別紙2「当事務所報酬規定」は本別紙から参照しているのみで、別途作成が必要。
