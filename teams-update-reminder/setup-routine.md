# Claudeルーティン セットアップガイド

毎朝9時に自動でGmailを確認し、期日超過者へリマインドメールを送信するルーティンの設定手順。

## セットアップコマンド

Claudeに以下のように依頼する：

```
teams-update-reminderのルーティンをセットアップしてください。
管理者メール：[管理者のメールアドレス]
```

## ルーティン動作の流れ

```
毎朝 09:00
    ↓
Gmail検索：件名「[TEAMS-OVERDUE]」の本日の未読メール
    ↓ メールあり
本文をパースして未提出者リストを抽出
    ↓
超過日数ごとにリマインドレベルを判定
    ↓
Gmail MCPでリマインドメールをドラフト作成
    ↓
（ユーザー確認なしで）送信実行
    ↓
完了レポートをユーザーへ通知
    ↓ メールなし
「本日の期日超過リスト：0件」でスキップ
```

## ルーティン設定時の注意

- Power Automateフローが08:30に実行されるため、Claudeルーティンは09:00に設定する
- Gmailに `teams-overdue` ラベルを作成しておくとメール検索が確実になる
- 管理者メールアドレスはスキル起動時に毎回入力するか、CLAUDE.mdに記載しておく
