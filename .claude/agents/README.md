# 事業計画 サブエージェント集（福田会計）

福田会計の事業計画を **業務カテゴリー別** にサブエージェント化して運用するためのディレクトリです。
`.claude/agents/` 配下に置かれた `*.md` は、Claude Code から専門担当者として呼び出せます。

## カテゴリー構成（全5種）

事業計画を業務カテゴリー別に分け、カテゴリーによってはさらにサブ領域へ細分化する。

| # | カテゴリー | サブ領域 | ファイル | 状態 |
|---|-----------|---------|---------|------|
| 1 | 人材活動 | 採用 / 教育 / 評価 | `human-resources-planning.md` | 未着手 |
| 2 | サービス品質活動 | （未細分化） | `service-quality-planning.md` | 未着手 |
| 3 | 営業マーケ活動 | （未細分化） | `sales-marketing-planning.md` | 未着手 |
| 4 | 戦略構築活動 | 事業計画 / 外部委託 / 業務提携 | `strategy-planning.md` | 未着手 |
| 5 | 財務経理活動 | （未細分化） | `finance-accounting-planning.md` | ✅ 試作済み（テンプレート） |

### 細分化の扱い方（設計方針）

サブ領域があるカテゴリーは、運用しながら以下のどちらかを選べる：

- **1エージェント内で章立てする** … サブ領域ごとにミッション・KPIの節を設ける（初期はこちらが軽量で推奨）
- **サブ領域ごとにエージェントを分ける** … 例 `human-resources-recruiting.md` / `human-resources-training.md` / `human-resources-evaluation.md`。担当者や判断基準が大きく異なる場合に有効

| カテゴリー | サブ領域と想定スコープ |
|-----------|----------------------|
| 人材活動 | **採用**＝採用計画・母集団形成・選考 / **教育**＝研修・OJT・スキル育成 / **評価**＝人事評価制度・査定・フィードバック |
| 戦略構築活動 | **事業計画**＝全社方針・中期計画の統括 / **外部委託**＝アウトソース方針・委託先選定 / **業務提携**＝アライアンス・協業先開拓 |

## 試作（テンプレート）について

まず **財務経理活動**（`finance-accounting-planning.md`）を試作しました。
これを「型」として、以下の共通構成を踏襲しながら残り4カテゴリーへ横展開します。

### 各エージェントの共通構成

1. **フロントマター** (`name` / `description`)
   - `description` に「いつ使うか（トリガーとなるキーワード・状況）」を具体的に書く
2. **ミッション** — そのカテゴリーで何を支援するか
3. **主要KPI／管理指標** — 定点観測する指標（初期セットは要ヒアリング）
4. **データソース** — MoneyForward / Google Drive / Asana など割り当てる連携先
5. **進め方の基本フロー** — 着手時の確認事項と作業手順
6. **判断・出力のルール** — 推測しない、要因と打ち手をセットで返す等
7. **確定済みの前提** — 福田会計で合意した数値・ルールを蓄積していく欄

## 運用の進め方

1. 試作（財務経理活動）を実際に使い、フォーマットの過不足を確認する
2. ヒアリングで「確定済みの前提」欄を埋め、精度を上げる
3. フォーマットが固まったら、残り4カテゴリーを同じ型で作成する
4. 各カテゴリーを横断する論点は「戦略構築活動」エージェントで束ねる

## 使い方（呼び出し方）

Claude Code 上で該当カテゴリーの作業を依頼すると、`description` のキーワードに
合致した際に自動でサブエージェントが選ばれます。明示的に指名することも可能です。
