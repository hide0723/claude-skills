# 期待職能（税理士法人福田会計版）

EMPグループの「給与テーブル期待職能（2024-09-01版）」を原型に、税理士法人福田会計の
グレード制度（T1〜EP／31グレード）に合わせて作成した期待職能表。

## ファイル

| ファイル | 内容 |
|---|---|
| `期待職能_福田会計.md` | 本文（正）。職能別の期待職能・昇格要件・運用ルール・未確定事項 |
| `期待職能_福田会計.xlsx` | A3横1枚に印刷できる一覧表。`build_xlsx.py` で生成 |
| `build_xlsx.py` | xlsx 生成スクリプト（openpyxl） |

## 生成

```bash
pip install openpyxl
python3 build_xlsx.py   # → 期待職能_福田会計.xlsx
```

内容を変更するときは `build_xlsx.py` の `ROWS` / `NOTES` と `期待職能_福田会計.md` の
両方を直してから再生成する。

## EMP版からの主な変更点

| 論点 | EMP版 | 福田会計版 |
|---|---|---|
| 段階数 | 9段階（入社前・S・SS・CS・M・SM・GM・D・P） | 8段階（入社前・T1・S・SS・M/SM・D/SD・P・EP） |
| CS（チーフスタッフ） | 独立した階層 | SS（主任）に統合 |
| T1（研究生） | なし | 新設。期待売上高・労働分配率は問わない |
| 組織人数要件 | 20名／10名／6名／3名 | 15名／10名／6名／3名（所属人数 約10名に合わせて縮小） |
| 事業立ち上げ額 | 3億／1億 | 3,000万／1,000万（法人規模に合わせて1/10） |
| 売上基準 | 記載なし | グレード別「期待売上高」を明記（基本給テーブルと一致） |
| 資格要件 | 記載なし | 簿記3級（S）／簿記2級（SS）／税理士3科目（D）／税理士登録（P・EP）を仮置き |
| 残業ペナルティ | 記載なし | 月30時間超でグレードダウンを明記 |
| ハンドブック・MBS | EMPハンドブック／MBS1〜5 | 「所内ハンドブック試験」に置換（体系は未整備・要決定） |

## 運用開始前に決めること

`期待職能_福田会計.md` の「4. 未確定・要決定事項」を参照。所内ハンドブックの有無、
資格要件を必須とするか、拠点長の「拠点」の定義、バックオフィス職の評価方法など、
代表決裁が必要な項目を6点挙げている。
