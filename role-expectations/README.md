# 期待職能（税理士法人福田会計版）

EMPグループの「給与テーブル期待職能（2024-09-01版）」を原型に、税理士法人福田会計の
グレード制度（T1〜EP／31グレード）に合わせて作成した期待職能表。

## 構成

内容は **`levels.py` の1箇所** にまとまっていて、md / xlsx / html はそこから生成する。
3つのファイルを個別に手直しすると必ずズレるので、**必ず `levels.py` を直して再生成する**こと。

```
levels.py            ← 内容（職階・テーマ・測定指標・運用ルール・要決定事項）
  ├─ build_md.py    → 期待職能_福田会計.md    本文
  ├─ build_xlsx.py  → 期待職能_福田会計.xlsx  A3横1枚の印刷用
  └─ build_html.py  → 期待職能_福田会計.html  スマホ閲覧用
```

```bash
pip install openpyxl
python3 build_md.py && python3 build_xlsx.py && python3 build_html.py
```

## 項目名（EMP版からの読み替え）

| EMP版 | 福田会計版 |
|---|---|
| タイトル | 職階 |
| 主な役割 | テーマ |
| 昇進試験＆条件 | 昇格の条件 |
| 期待職能 | 期待される役割 |
| 期待されるパフォーマンス（フロントオフィス） | 測定指標1（関与先担当） |
| 期待されるパフォーマンス（バックオフィス） | 測定指標2（総務・経理） |
| 期待されるプロセス | 期待されるプロセス（変更なし） |
| ラーニングラダー必須書籍リスト | 必要なインプット |

測定指標1は関与先を担当する職員、測定指標2は総務・経理に適用する。兼任者は両方を見る。

## EMP版からの主な変更点

| 論点 | EMP版 | 福田会計版 |
|---|---|---|
| 段階数 | 9段階（入社前・S・SS・CS・M・SM・GM・D・P） | 10段階（入社前・T1・S・SS・M・SM・D・SD・P・EP） |
| CS（チーフスタッフ） | 独立した階層 | SS（主任）に統合 |
| T1（研究生） | なし | 新設。期待売上高・労働分配率は問わない |
| M・SM／D・SD | 記号ごとに1階層 | テーマを分けて別建て（M/SM、D/SD をそれぞれ独立） |
| 組織人数要件 | 20名／10名／6名／3名 | 15名／10名／6名／3名（所属人数 約10名に合わせて縮小） |
| 事業立ち上げ額 | 3億／1億 | 3,000万／1,000万（法人規模に合わせて1/10） |
| 売上基準 | 記載なし | グレード別「期待売上高」を明記（基本給テーブルと一致） |
| 資格要件 | 記載なし | 簿記3級（S）／簿記2級（SS）／税理士3科目（D）／税理士登録（P・EP）を仮置き |
| 残業ペナルティ | 記載なし | 月30時間超でグレードダウンを明記 |
| ハンドブック・MBS | EMPハンドブック／MBS1〜5 | 「所内ハンドブック試験」に置換（体系は未整備・要決定） |

## 未確定箇所の印

本文中の **【要決定】** は制度自体が未整備の項目、**【仮】** は数値・条件が仮置きの項目。
どちらも `levels.py` の `DECISIONS`（本文「4. 未確定・要決定事項」）に対応する。
運用開始前に代表決裁が必要なものを7点挙げている。
