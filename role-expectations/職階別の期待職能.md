## 0. この表の使い方

- 「期待される役割」は、**そのグレードに在籍する人に求められる状態**を示す。昇格の可否は、下位グレードの期待される役割を**満たしていること**を前提に、上位グレードの「昇格の条件」で判定する。
- **測定指標1** は関与先を担当する職員（フロントオフィス）、**測定指標2** は総務・経理（バックオフィス）に適用する。兼任者は両方を見る。
- 半期（12月〜5月／6月〜11月）ごとの評価面談で、**この表の文言そのものを使って**フィードバックする。文言は直属上司が起案し、代表が承認、上司から本人へ通知する。
- そのため上司は、日頃から部下を観察し、この表の項目で語れる状態にしておくこと。
- **【要決定】** は制度自体が未整備の項目、**【仮】** は数値・条件が仮置きの項目。いずれも「4. 未確定・要決定事項」に対応する。

## 3. 福田会計固有の運用ルール

### 3-1. 期待売上高（想定貢献報酬額）

```
期待売上高 ＝ 基本給上限 × 2 × 1.3 × 1.15 × 14
                 （千円未満切上）
```

- ×2 … 給与の倍を稼ぐ前提
- ×1.3 … 手当込みの総支給
- ×1.15 … 社会保険の会社負担
- ×14 … 賞与（夏冬2ヶ月）込みの支給月数

### 3-2. 給与総額比率

```
給与総額比率 ＝ 給与総額 ÷ 期待売上高
```

基準値は 50%。新卒は12ヶ月分、中途採用は6ヶ月分の給与を計算上考慮しません。

従来の労働分配率（給与総支給 ÷（契約報酬 ÷ 2）／基準43%）から置き換えました。賞与算定シートの計算式は旧定義のままのため、突き合わせが必要です。

### 3-3. 賞与判定との連動

```
修正貢献報酬額 ＝ 契約報酬(6ヶ月)
                 ＋ インセンティブ(6ヶ月) × 25%

差額 ＝ 修正貢献報酬額 − 想定貢献報酬額
  差額 ≧ 0 → 支給額 ＝ 差額
  差額 < 0 → 支給額 ＝ 基本給1ヶ月分
```

### 3-4. 残業ペナルティ

月平均残業が30時間を超えた場合、評価グレードを引き下げます。

- S … 2グレードダウン
- SS〜SM … 1グレードダウン
- T … 考慮しない

### 3-5. 読書レポートと宣言書

レポートの提出に伴い、1通ごとに2,000円の補助を支給します。

宣言書は、自身が期待される役割・測定指標を満たしていることを、根拠と共に記した文書。昇格申請時に提出します。

### 3-6. フィードバックの進め方

半期（12月〜5月／6月〜11月）ごとの評価面談で、この表の文言そのものを使ってフィードバックします。文言は直属上司が起案し、代表が承認、上司から本人へ通知します。

そのため上司は、日頃から部下を観察し、この表の項目で語れる状態にしておくこと。

## 4. 未確定・要決定事項

以下は EMP 版から福田会計版へ移す際に、**福田会計として決め切れていない**項目。運用開始前に代表決裁が必要。

1. **虎の巻試験の中身** — 虎の巻そのものは存在し日次で更新しているが、EMP版の「MBS1〜5」に相当する研修体系と、そこから出題する昇格試験の実体が未整備。出題範囲・合格基準・実施時期を決める必要がある。
2. **資格要件を必須にするか** — 簿記3級(S)／簿記2級(SS)／税理士3科目(D)／税理士登録(P・EP) は仮置き。必須条件か、参考条件に留めるか。
3. **組織人数要件** — EP=15名／P=10名／D・SD=6名／SM=計6名／M=3名。EMP版（20/10/6/3）を所属約10名の規模に合わせて縮小した仮置き値。
4. **「拠点」の定義** — 現在は単一拠点。部門（法人担当／個人担当／総務）を拠点とみなすかどうか。D・SDは在籍者ゼロの将来枠。
5. **新サービス立ち上げ額** — EP=3,000万円／P=1,000万円。EMP版（3億／1億）を法人規模に合わせて1/10に縮小した仮置き値。
6. **バックオフィス職の評価軸** — 総務・経理は契約報酬なしでT1扱い。期待売上高に代わる測定指標（処理件数・期限遵守率など）を何にするか。
7. **T・S の中身の確定** — 研究生（T）の昇格の条件と、担当職（S）の期待される役割・昇格の条件・測定指標1 はセクションごと仮置き。実際の新人教育カリキュラム（虎の巻・オンボーディング）が固まってから確定させる。
8. **ATC対応表の突き合わせ** — アチーブメント公式サイトを直接参照できなかったため、ATCの学習項目は公開されている二次情報と所内の『グラッサー博士の選択理論』から構成した提案。実際の受講テキストと突き合わせて項目名・粒度を確定させること。あわせて、ATC受講をM（部長）に置いたままでよいか（下位職階での受講時期）も要検討。
9. **統合後のテーマ（部長）** — M と SM を1つの「部長（M1〜SM3）」に統合することは決定済み。統合後のテーマを「チーム力の向上」「チーム間の相乗効果」のどちらにするか、あるいは別の言葉にするかが未定。決まるまでこの表は9職階のまま。
10. **統合後のテーマ（拠点長）** — D と SD を1つの「拠点長（D1〜SD3）」に統合することは決定済み。統合後のテーマを「マネジャーの育成」「計画策定と事業推進」のどちらにするか、あるいは別の言葉にするかが未定。「拠点」の定義（4）とあわせて決める。
