# 賞与計算スキル（福田会計）

> ⚠️ **本スキルはドラフトです。** 実際の賞与計算シート（R7版）から計算ロジックを
> 読み取って起こした初版で、係数・按分ルール・CSV列構成は **ユーザー確認待ち** の項目を含む。
> 確定した内容は「確定済みの前提」へ移し、`【要確認】` を消していく。

## 概要

福田会計では、スタッフ各人の **担当顧問先への請求額（売上）** を基礎に賞与を算定する。
税理士事務所特有の事情として、季節性の高い **特別業務**（所得税確定申告・年末調整・
償却資産申告・株式評価）を、実施者と検査者で按分して各人の貢献に反映する。

本スキルは2つの場面を支援する：

1. **月次** … 評価期間中、担当者別売上明細を作成して回覧（印刷配布）し、賞与原資を積み上げ見える化する
2. **賞与時（夏・冬の年2回）** … 担当者別売上＋特別業務按分から賞与支給額を算定する

## 賞与サイクルと評価期間

- 年2回（夏・冬）支給
- 評価期間は6ヶ月。例：冬賞与 = R7.12.01〜R8.5.31
- 特別業務は通年で発生するため「夏・冬に分ける（÷2）」調整を行う

## 月次運用：担当者別売上明細の作成と回覧

### 入力データ

- **請求CSV** … 会計／請求システムからダウンロードした担当者別の請求データ
  - `【要確認】` ダウンロード元システム名と、CSVの列構成（担当者・顧問先・請求額・税区分・年月 等）
  - `【要確認】` 文字コード（Shift-JIS か UTF-8）

### 処理

1. CSVを読み込み、**担当者別**に当月および評価期間累計の請求額（税抜）を集計する
2. 顧問先調整・特別業務分があれば区分して表示する
3. 前月比・評価期間進捗（賞与原資の積み上がり）を付す

### 出力（印刷配布前提）

- **担当者別売上明細表** … 各担当者に配布する印刷向けレイアウト（A4想定）
  - `【要確認】` 配布は担当者本人の分のみか、全員分一覧か
  - `【要確認】` xlsx／PDF どちらで出力するか（印刷のしやすさ優先）

## 賞与計算ロジック（R7シートから解読・要確認）

> 下表の列記号は実シートの構成に対応。`年調50％` と `年調100％` の2シナリオで試算されている。

### Step 1: 担当者別の評価期間売上（A）

- **A = 評価期間の請求額（税抜） + 顧問先調整**
- `【要確認】` 顧問先調整（増減）の判断基準

### Step 2: 特別業務の按分（シート2のロジック）

特別業務 = 所得税請求額 / 年調請求額 / 償却資産請求額 / 株式評価。
各業務を **実施者** と **検査者** に配分する。

- 実施按分・検査按分を、**検査件数／人数** に応じて配分
- 各人の取り分 = 「実施＋検査」
- `【要確認】` 実施と検査の配分比率、件数・人数の取得元
- `【要確認】` 株式評価の作成者／検査者の対応（瀬戸ヶ原・森合資・アムズ・トマル等の割当ルール）

### Step 3: 賞与支給額の計算（列の流れ）

| 記号 | 項目 | 内容 |
|------|------|------|
| A | 評価期間の売上高 | Step 1 |
| B | 含む特別業務 | Aに含まれる特別業務分 |
| C | A − B | 通常業務分 |
| D | Bを検査反映・再配分 | Step 2 の按分結果 |
| E | C + D | |
| F | 共通費×0% | 現状0%（`【要確認】` 将来変更の有無） |
| G | 特別業務を夏・冬に分ける | D ÷ 2 |
| H | C + F + G | |
| I | **賞与支給原資 = H × 50%** | `【要確認】` 50%の根拠・固定か |
| J | 支払済給与 | 評価期間に支給済みの給与（控除） |
| K | 社保考慮 ×1.15 | `【要確認】` 1.15の根拠・固定か |
| L | I − K | 賞与支給額の計算結果 |
| O | 実際の支給額 | 最終調整後 |
| P | 報奨金（褒章） | 別途加算 |

- `【要確認】` 「年調50％」と「年調100％」のどちらを最終採用するか、その選択基準
- `【要確認】` 「実際の支給額」で計算値から手動調整する場合の判断（最低保証・端数処理 等）

## データソース

- **請求データ**: `【要確認】` 会計／請求システム（CSVダウンロード）
- **給与支給データ**: 評価期間の月次給与・冬賞与・年末調整（控除項目）
- **外部委託**: 一部担当者に外部委託費の調整あり（シート上 `外部委託` 行）
- 連携可能なら MoneyForward / Google Drive 等から取得を検討（`【要確認】`）

## 判断・出力のルール

- 推測で数値を埋めない。係数・按分ルールが未確定なものは `【要確認】` のまま残し、ユーザーに確認する
- 金額は単位（円）を明示し桁を揃える
- 計算過程（A→Lの各列）を追えるよう、中間値も残して提示する
- 最終支給額の決定は所長・経営判断である前提で、計算結果と根拠を提示する
