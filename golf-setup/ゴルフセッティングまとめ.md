## 根本原因：アウトサイドインの軌道（最重要の発見）

バッグ中に散らばって見えた症状は、すべて同じ軌道から出ている。

| クラブ | 症状 | 軌道との関係 | これまでの対処 |
|---|---|---|---|
| ドライバー | 左に巻く | 軌道が左向き＋フェースが閉じる＝プルフック | 重い・低トルク・先端しっかりのシャフト |
| アイアン | **トゥ当たり・距離落ち** | ヘッドが内側に抜けるため接点がトゥ寄りに | オフセット少なめの225（返りすぎない）|
| ウェッジ | ダフリ | 入射が鋭くなりリーディングエッジが刺さる | ハイバウンス（GS 53°）|
| パター | フェースバランスだとプル | ストロークも同じ軌道でカット気味 | トーハング30°のブレード |

- **道具は正しく効いている**。アンチ左・低オフセット・ハイバウンス・トーハングは、すべて筋の通った対処。
- **ただしトゥ当たりの距離落ちは道具では直らない**。ポケキャビは落ち幅を小さくするだけで原因は残る。→ **ここがティー→グリーン −5打の在処**。
- **軌道が改善すると要求水準が全部下がる**（打点が芯に寄る／左が減ってアンチ左の道具に頼らず軽いシャフトで距離も戻る／パットの出球も揃う）。
- **ライはフラットのまま**。トゥ当たりを見てアップライトにすると左が増える。※フェース打痕の位置は構えと軌道の話、**ライ診断はソールの擦り跡**で行う。

## ドライバー

- **ヘッドはMAX-Kで確定**。LS＋T1100は**右へすっぽ抜け**（LSは重心が前寄りで返りにくい × 硬い先端＝アンチ左が二重）。MAX-K＋T1100では出ない。
- 加えて**高MOI＝ダボ削減**、**打ち出し確保**（低スピン過多の是正）。
- **次のテスト：MAX-K固定で T1100 65g vs KBS TD Black 60 S**。見るのは**平均キャリー**と**左右の散り**。
  - **片側のミス** → バイアスの問題（ウェイト／ライで調整）
  - **両側のミス** → 安定性不足（重い方＝T1100に戻す）
- ウェイトは**ニュートラル〜フェード**（MAX-Kはつかまり系）。打ち出しが低ければ10.5°へ。
- ※LSを使う時は**ウェイトをニュートラル・ライを1°アップライト**。

| | 内容 |
|---|---|

## ウェッジ

**設計思想**：フルショット＝アイアン群（Modus³130）／コントロール・グリーン周り＝ウェッジ群（KBS610）。
**距離配分**：100〜30yは**50°と53°を振り幅で**打ち分け。3本目は**30y以下限定**。→ **56°帯のフル番手は不要**。

### 確定：GS 53°（実52°・ハイバウンス・466g）
- **〜30yのコントロール（MVP）**。ラフに強く、**ざっくりが出ない唯一のクラブ**。
- **高め・柔らかい・止まる球**。50°と2°差だが、シャフト・ソール・弾道が別物＝**同じ距離を2つの弾道で打ち分ける道具**。
- **GSの中で唯一の「ハイバウンス＝刺さらない」1本**。

### 未確定①：50°（100y〜のフル／コントロール）
| 候補 | 強み | 弱み |
|---|---|---|
| **Z525 AW 50°**（459g / PX5.5）| **実績あり** ＋ **ポケキャビ＝トゥ当たりに強い** | PWと系統が変わる・バウンス不明 |
| **Cleveland RTZ 50-10**（KBS610 125）| **バウンス10で刺さりにくい** ＋ **56-10と完全に揃う** | 実績は「悪くないが使わなかった」止まり |
| ミズノ MP T5 50°（467g）| フルソール・225と同ブランド | Modus³130を挿す必要／バウンス不明 |

**判定＝①100y届くか ②トゥに当たった時の距離落ち。**
※フル番手は**フル幅ソール必須**（削りの多いソールは実効ロフトが寝てショートする＝GS 49°の失敗）。

### 3本目：実打テストの結果（30y以下・ショートサイド）

**アプローチ練習場での比較テスト（4本）**

| | 20yラフ | 10yグリーンエッジ | 5y・薄い芝・左足下がり |
|---|---|---|---|
| **A** Cleveland RTZ 56-10 | ✅ **ミス最少**・縦ブレ | **トップ系** | **トップ系** |
| **B** アクシス Z2 58°（KBS Tour V）| ✅ 縦ブレ | **トップ系** | **トップ系** |
| **C** Artisan 56°（SB・重グリップ）| △ 縦ブレ・**やや大きい** | **ざっくり系** | 綺麗に入るが**止まらない** |
| **D** モダート 58°（Modus³130）| ⚠️ **横ブレ** | **ざっくり系** | ✅ **綺麗に入り、止まる** |

### 読み取れた構造：2つの family
- **A・B＝バウンスが効く**：草を滑って**ラフに強い**。反面、**薄いライではソールが跳ねてトップ**。
- **C・D＝エッジが入る**：普通の短いライで**刺さってざっくり**。反面、**薄い・下り傾斜でボールの下に入る**。
- **BはAと全項目で同挙動＝役割が完全に重複**。どちらか1本でよい（実績のあるAが自然）。

### 選定の原則：GS 53°と“被らない”1本を選ぶ
**GS 53°（ハイバウンス）＝A/Bと同じ family**。したがって：

| 組み合わせ | 結果 |
|---|---|
| GS 53° ＋ A（またはB）| **同じ性格が2本**。薄いライ・下り傾斜に打つ手がないまま |
| **GS 53° ＋ D** | **バウンス系＋エッジ系＝あらゆるライをカバー** |

→ **Dの弱点（ラフでの横ブレ）はGS 53°が担当する領域**なので、実質的な弱点にならない。

### 推奨：3本目＝**D（モダート58° × Modus³130）**
- **最も難しい「薄いライ・下り傾斜・止めたい」ショットで唯一機能**した。
- 以前モダートを「打感が異物」として外したのは**理論上の判断**。**実測が上回るなら実測を採る**（自分ルール「仮説より実物」）。
- Modus³130という重めのスチールが、繊細なショットで**ヘッドの位置を感じさせている**可能性。

### ⚠️ 残る穴：バンカーが未テスト
3本目はバンカーも担当する。**Dは刺さる側＝柔らかい砂で潜るリスク**／**Aは硬い砂で実証済み**。
→ **次はバンカーでAとDを打ち比べる**。
- Dが砂でも出せる → **Dで確定・ウェッジ完成**
- Dが砂で潜る → 「薄いライ用のD」と「バンカー用のA」のどちらを取るか、**4本目の枠を作るか**の判断へ

### ⚠️ Cは判定保留
Artisan 56°は**重いグリップが付いたまま**でのテスト。**標準重量に戻して再テストするまで結論を出さない**（過去の誤診パターンを繰り返さないため）。

### ダフリ持ちのための鉄則
- **ハイバウンス（GS 53°）が主軸＝刺さりを防ぐ**。**削りの多いソール（GS 49°/61°、Artisan DS）は開いて使う番手**で、スクエアで打つと刺さる。
- **グリップ加重はしない。重いグリップに替えるのも同じこと**（鉛か素材かの違いだけ）。
- **60° DSは必ず開いて使う**。スクエアで低く打つと削りが刺さる。

### 不要（バッグ外）
| クラブ | 理由 |
|---|---|
| GS 49°（463g）| 削りソールでフル時にロフトが寝て100yショート＝距離番手に不適 |
| GS 57°（実58°）| 61°と同ロフト・感触不良 |
| GS 47° | 練習場のみ・未実戦 |
| Artisan 50° S | 50°枠と重複 |
| Artisan 56° SB | 実打で**ざっくり系＋ラフのブレ最大**。ただし**重グリップのまま**＝標準に戻して再テストするまで保留 |
| **アクシス Z2 58°（KBS Tour V）** | **Cleveland 56-10と全項目で同挙動＝役割が完全に重複**。実績のあるCleveland優先 |
| **Cleveland RTZ 56-10** | ラフには最も強いが**GS 53°と同じ family**＝役割が重複。※**バンカー要員として復帰の可能性あり** |

## ボール：Srixon Z-Star ダイヤモンド（確定）

- 旧：Pro V1x レフトダッシュ（最低スピン）＝**低スピン全部乗せ**の一因。

## 自分ルール（実戦から確定した法則）

| ルール | 根拠 |
|---|---|
| **グリップ加重はしない**（重いグリップも同じ）| 50°が100yショート／57°でバンカーホームラン／G430が19°と同距離 |
| **ハイバウンスが合う** | ミスはダフリ＝刺さり。GS 53°だけざっくりが出ない |
| **左を消すのは重さでなく先端剛性** | WS40（40g）は左／Green 65は左減・距離減 → TD Black 60Sで両立を狙う |
| **安定は硬さでなく重量とトルクで作る** | 硬いシャフトは調子が落ちると合わない（KBS Proto・テンセイ白X）|
| **両側のミス＝安定性不足／片側＝バイアス** | Tour AD HY 65 Sは両側 → 重量で安定を足す |
| **パターはトーハング必須** | フェースバランスはプル。B60が過去ベスト |
| **低スピンギア × 高スピンボール** | 225 × Z-Star ダイヤで黄金バランス。アイアンは替えなくてよかった |
| **ソール形状が実効ロフトを変える** | GS 49°が100y届かず → フルソールへ |
| **残せるミスと、残せないミス** | 「短い」は花道、「左」は2打失う → 225継続 |
| **仮説より実物** | 理論上の最適と実績がぶつかったら実測を採る |
| **ボールはグリーンから逆算** | ドライバーはクラブ側で調整できる |

## 雨天・濡れたコンディション

- **バンカー**：雨＝砂が締まる → **ハイバウンスは弾かれてホームラン**しやすい。**低バウンス（Artisan系）に入替**。
- **グリーン周り**：ぬかるみ＝ハイバウンス据え置き／締まったライ＝低バウンスへ。
- **距離**：ランが出ない＝1番手上げる／濡れラフ＝フライヤー想定。
- G430（ハイブリッド）は濡れFWから拾いやすく**雨ではむしろ有利**。グリップの劣化チェックを。
