## プレーヤープロフィール

| 項目 | 内容 |
|---|---|
| レベル | 上級者（平均80台） |
| 目的 | ① 飛距離アップ ② クラブの過不足（ギャップ）解消 |
| 長い番手の哲学 | **ライ別に打ち分け**（下記参照） |
| ウェッジの好み | カウンターバランス（グリップ加重で“振りやすい”＝成功している） |

### 長い番手の打ち分け哲学
| 状況 | 使うクラブ | 理由 |
|---|---|---|
| フェアウェイ（芝） | **UT** | ソールが滑って拾いやすい・上がりやすい |
| ショートのティーショット | **アイアン型（プロト27°）** | 低く出して縦距離が安定・構えやすい |
| 夏の濃いラフ | **アイアン型（プロト27°）** | コンパクトヘッドで草が絡みにくくフェースが返りにくい |

→ UT26°（26°）とプロト27°（27°）は1°差だが、**ライ別最適化のため両方所持は妥当**（無駄ではない）。

## ロフト階段（実ロフト基準）

```
Driver → 16° → UT19 → UT22 → UT26 → 27(プロト) → 7i(31) → 8i(35)
→ 9i(40) → PW(44) → W①(48〜50) → W②(52〜56) → W③(58〜60)
```
- ウェッジ以外：最大4〜5°で良好
- ウェッジ：許容範囲の最大6°でOK（本人合意済み）

```
SH 359 → UT 368 → 390 → 405 → プロト418 → 7i〜444 → 8i〜451
→ 9i459 → PW467 → ウェッジ473〜483
```

## シャフト連続性（合格）

- アイアン：**Modus³130 S**（約130g）
- ウェッジ：**KBS610 wedge120**（約120g）
- → Modus130 → KBS120 は上級者の鉄板ペア。GS・アーティザン**どちらもKBS610 wedge120で同一**＝シャフト面の差はゼロ。
- フレックスは全体**S統一**（ドライバーWS40 S／SH DI85 S／アイアンModus S）。

## ウェッジ最終決定：GS vs Artisan（実ロフト待ち）

両者とも **KBS610 wedge120**・**カウンターバランス済み**・**3本構成**。差はヘッドとロフト構成のみ。

### 表示ロフト vs 実ロフト（重要）
| クラブ | 表示 | 実ロフト |
|---|---|---|
| GS 53° | 53 | **52°** |
| GS 61° | 61 | **58°**（＝普通に使えるロブ）|

→ 「GS 53/61は8°の穴」は**表示ロフト基準の誤判定**。実ロフトでは下記の通り問題なし。

### 比較（実ロフト基準・PW実44°想定）
| 案 | 実ロフト構成 | ギャップ | 細かいゾーン |
|---|---|---|---|
| **GS 49/53/61** | ~48 / 52 / 58 | **4 / 4 / 6°** | フルショット帯（上）が細かい＝スコア向き |
| Artisan 50/56/60 | 50 / 56 / 60※ | 6 / 6 / 4° | ロブ帯（下）が細かい |

- **現時点の推奨：GS 49/53/61（実48/52/58）**
  - 気に入っている49・53をそのまま使える
  - 不満だった57°を排除済み（57実〜55°と61実58°が2〜3°差で差別化できなかったため排除は正解）
  - フルショット帯（縦の刻みが効く所）が4/4°と細かい

## ウェッジで“本当に”大事な未検討項目

優先順位：①ロフトギャップ（済）②**バウンス＆グラインド（未）** ③打感/バランス（済）④ウェッジ間総重量（緩くてOK）

  - 1g単位の重量合わせより遥かにスコアに効く。
