- フォーメーション①: 4-4-2ダイヤモンド（カウンター・ハイプレス）
- フォーメーション②: 4-3-3（ショートカウンター対応）

---

## 4-4-2ダイヤモンド スタメン配置

```
           ベイル(LWG)
    フリット(ST)  オーウェン(CF)
         イニエスタ(OMF)
   ペドリ(CMF左) ネドベド(CMF右)
           ロドリ(DMF)
グヴァルディオル  カンナバーロ  ファーディナンド  サリバ
(LSB)     (前CB)     (後CB/スイーパー)   (右端CB)
```

### バックライン詳細
- **LSB**: グヴァルディオル（攻め上がり可・インナーラップ対応）
- **前CB（ストッパー）**: カンナバーロ（ハードプレスタイプ）
- **後CB（スイーパー）**: ファーディナンド（カバーリング・ロングパス）
- **右端**: サリバ（対人守備）

### 中盤詳細
- **DMF**: ロドリ（アンカー、ラインダウン設定）
- **CMF左**: ペドリ（ラインダウン設定・ロドリ横スペースカバー）
- **CMF右**: ネドベド（攻撃参加・フライパス83）
- **OMF**: イニエスタ（2列目からの飛び出し・ボールキープ）

### フォワード詳細
- **LWG**: ベイル（カウンターターゲットON・クロス受け）
- **ST**: フリット（2列目からの飛び出し・カウンター先端）
- **CF**: オーウェン（ボールキープ88・決定力）

## 控え・代替選手

| ポジション | 選手 | 備考 |
|---------|------|------|
| LSB控え | ファン・デ・フェン | スピード対応・高さ対応 |
| CB控え | ネスタ（候補） | カンナバーロ同タイプ |
| CMF右控え | ジェラード（候補） | フライパス89・スタミナ93 |
| CF控え | スアレス | ボールキープ82（ロスト多め） |
| WG候補 | ロナウジーニョ | LWG/RWG |
| WG候補 | メッシ | RWGまたはST横 |

## 個人設定メモ
- **グヴァルディオル**: 攻め上がり（インナーラップ活用）
- **ロドリ**: ラインダウン
- **ペドリ**: ラインダウン（DMF横スペースカバー）
- **ベイル**: カウンターターゲットON

## 4-3-3 配置（ハーランド・デンベレ・エンバペ等スリートップ対応）

```
  クライフ/メッシ(RWG)  フリット(ST)  ベイル(LWG)
       ネドベド(CMF)  ペドリ(CMF)
              ロドリ(DMF)
LSB    CB(横並び)    CB(横並び)   右端
```

### 4-3-3メモ
- CBは横並び（同深さ）
- ショートカウンター主体
- ハーランドのようなスピードFWへの対応にLSBをファン・デ・フェンに
