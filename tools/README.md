# tools

事務所業務のちょっとしたスクリプト置き場です。

## asana_assignment_list.py（担当一覧表 HTML ジェネレータ）

Asana プロジェクト「40.税務業務：契約・提案用」のタスクから、SharePoint
「30.担当一覧表」の月次 Excel（`RX年MM月担当一覧表.xlsx`）と同じ書式の
HTML ページを組み立てます。

- **行** … 決算月（1月〜12月／個人／給(有)／給(無)）＝カスタムフィールド「決算月」
- **列** … 担当者＝タスクが属する Asana セクション（＋未割当／CAV）
- **セル** … 関与先名＋ランクバッジ＋他関与者＝「ランク」「他関与者1」。
  関与先名は Asana のタスクへのリンク（`permalink_url`、無ければ gid から組む）。
  名前の後ろの括弧書き（「（ミルキーウェイ）」「（9月解約）」など）は 2 行目に
  送り、列幅が「本体と括弧書きの長いほう」で済むようにしている。先頭の法人格
  （`(医)` `(一社)` など）と、末尾の短い法人格（`(同)` `(資)` など）は切らない
- **件数** … 各決算月行の担当者列の合計（CAV 列と補助業務行「補ー決算／補ー月次」を除く）
- **合計** … 各列に載る全件数

生成されるのは外部リソースを一切読まない単一 HTML です。ランク／担当者での
絞り込み、関与先名の検索、他関与者の表示切替、解約・完了済の表示切替がその場で
動きます。ライト／ダークどちらのテーマでも読めます。

セル幅の上限は `--entry-cap`（画面）と `--entry-cap-print`（印刷）で持っています。
画面は担当者列を多く並べたいので詰め、A3 に刷るときは横に余裕があるので広げます
（縦に伸びると縮小率が下がって字が小さくなるため）。実測では画面 1500px で
17em→6 列、12em→8 列、11em 以下は列数が増えませんでした。

「その他にまとめる」を入れると、南雲・齋籐・英明・高崎：石倉・未割当・CAV が
1 列に畳まれます（列数 13→8、幅 2419→1579px）。畳んだ列の各行には元の担当名を
小さく添えます。件数の数え方は変わりません（CAV他関与と補助業務行は除いたまま）。
まとめる顔ぶれは `OTHER_MEMBERS` です。

表題下の集計は折り畳みです。集計と最下部の注記は印刷には出ません（紙に載るのは
表題と表だけ）。「他関与者を表示」を外すと、
マトリクスの「＋担当者名」と、一覧・ドリルダウンの「他関与者」列が畳まれます。

### タブ

| タブ | 中身 |
| --- | --- |
| 担当一覧表 | 決算月×担当者のマトリクス（Excel と同じ書式） |
| 一覧 | 全件をフラットな表で |
| 令和N年新規 | その年に Asana に登録された関与先を登録日順に。年間報酬額と合計行つき |
| 契約書未添付 | 添付に「契約」を含むファイルが無い関与先を報酬額の大きい順に |
| 前月比 | 前月のスナップショットとの差分（増えた先／消えた先／変わった項目） |

新規タブはデータに出てくる直近 2 年ぶんが自動で並びます。年が変われば勝手に
繰り上がるので、手を入れる必要はありません。

「年間報酬額」は Asana の「契約報酬額（年額）」、「登録日」はタスク作成日
（`created_at`）です。Asana に契約開始日の
項目がないため、新規関与先の目安としてこれを使っています。数え方は「件数」列
と同じで、CAV他関与と補助業務行「補ー決算／補ー月次」は除きます。

### 集計タイルから関与先を引く

「Aランク」「給与計算」「CAV他関与」「担当未割当」は数字を押すと、該当する
関与先の一覧がその場で開きます。表の絞り込みは変わりません。

### 月次スナップショットと前月比

実行するたびに `--snapshot-dir`（既定 `snapshots`）へ `RNN年MM月.json` を書き出し、
次回の実行時に「今回以外で一番新しいスナップショット」を読んで HTML に埋め込みます。
前月比タブはその差分を出すだけなので、サーバは要りません。

- 照合の鍵はタスクの gid。名前が変わっても同じ先として追えます
- 見るのは 担当／ランク／決算月／年間報酬額／関与先名／他関与者 の 6 項目
- 「消えた先」は、前月は在籍していて今月は完了済（またはデータから消えた）先
- 初回は前月ぶんが無いので空になります。その旨がタブに出ます

**スナップショットには関与先名と報酬額が入ります。** リポジトリ外の場所を
`--snapshot-dir` に指定してください（SharePoint や OneDrive の同期フォルダなど）。
`--no-snapshot` で読み書きを止められます。

### 顧問契約書の添付チェック

`opt_fields` に `attachments.name` を入れて書き出すと、添付ファイル名に「契約」を
含むものが無い関与先を「契約書未添付」タブに並べます。判定に使う文字は
`CONTRACT_PATTERN`（Python）と同名の定数（HTML 側）で、両方を揃えて直してください。

添付を取っていないデータでは判定できないので、そのときはタブに取得方法だけ出ます。
「Asanaと同期」ボタンからの取り込みでは自動で添付も取りに行き、`attachments` を
受け付けない環境では添付なしで取り直します。

### Asana と同期

「Asanaと同期」ボタンから、ページ自身が Asana を叩いて最新化できます。
個人用アクセストークン（Asana の［設定］→［アプリ］→［個人用アクセストークン］）
が要ります。「このブラウザに保存する」に入れると localStorage に残るので、
共用パソコンでは入れないでください。

社内ネットワークやブラウザの制限で直接つながらない場合は、同じダイアログから
書き出し済みの JSON を読み込めます（複数ページ分をまとめて選択可）。
どちらの経路でも、表題横の「Asana同期」の日時が更新されます。

### 印刷・PDF 出力

「印刷 / PDF保存」ボタン（またはブラウザの印刷）で、**画面に出ている絞り込みの
まま**刷れます。テーマに関わらず白地・黒字になります。

- **担当一覧表タブ** … A3 横 1 枚。表題ぶんを差し引いた領域に対して、表の幅を
  二分探索して**紙をいちばん大きく使える組み方**を選びます。表の縦横比が紙の
  縦横比に一致したところが最大になるので、そこを挟み込みます（幅か上限値の
  片方を決め打ちにすると、右か下が余ってそのぶん字が小さくなります）。担当者を絞る／ランクを外すと表が小さくなるぶん、文字は
  大きく刷れます。
- **その他のタブ** … A4 縦。見出し行を各ページの先頭に繰り返します。

PDF にするときはブラウザの印刷ダイアログで「PDF に保存」を選んでください。
用紙サイズと余白は CSS 側で指定しているので、ダイアログ側は既定のままで構いません。

### 使い方

```bash
# 1. Asana からタスクを書き出す（next_page.offset を辿って全ページ取得する）
curl -H "Authorization: Bearer $ASANA_TOKEN" \
  "https://app.asana.com/api/1.0/tasks?project=1204361669585488&limit=100&opt_fields=\
name,completed,created_at,permalink_url,memberships.section.name,custom_fields.name,custom_fields.display_value" \
  > page1.json

# 2. HTML を組み立てる
python3 tools/asana_assignment_list.py page*.json -o 担当一覧表.html --era "令和8年8月度"
```

Claude Code から Asana MCP（`get_tasks`）で取得した JSON もそのまま渡せます。
`--era` を省略すると実行日から和暦を組み立て、`--synced` を省略すると実行時刻を
同期日時にします。`created_at` を落とすと新規タブが空になるので、opt_fields に
必ず入れてください。`permalink_url` は無くても gid からリンクを組みます。

依存パッケージはありません（Python 3.10 以降の標準ライブラリのみ）。

### 担当者列を変えるとき

`STAFF_COLUMNS` が列の並びです。Asana のセクション名と綴りを合わせてください
（例: `松﨑` は「立つ崎」）。ここに無いセクションのタスクは「未割当」列に入ります。

Python の `normalize()` と HTML 側の `normalizeTasks()` は同じ変換規則を持って
います。同期ボタンで取り込み直しても同じ表になるよう、片方を直したらもう片方も
直してください。

### 顧客情報の取り扱い

このリポジトリは公開されています。**関与先名・報酬額を含む JSON や、生成した
HTML をコミットしないでください。** 出力先はリポジトリ外を指定してください。
